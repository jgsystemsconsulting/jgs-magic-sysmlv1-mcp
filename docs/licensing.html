Licence & tiers

Three tiers. Read for free, write with a licence.

The FREE tier reads and audits your model with no licence file. PRO adds full write access so your agent can author and refactor the model. ENTERPRISE adds Groovy scripting and destructive operations for large, repeatable changes. Contact JG Systems Consulting for PRO and ENTERPRISE licences.

Place your licence file

Your licence file (jgsc-sysmlv1-pro.licence) is issued by JG Systems Consulting Ltd. Place it alongside the PRO JAR in your CATIA Magic plugins directory: 

plugins/com.jgsc.magicmcp.sysmlv1/jgs-pro/jgsc-sysmlv1-pro.licence
The plugin reads the licence on startup. After restarting CATIA Magic, confirm it was detected with the get_licence MCP tool.

Verify your licence

Inspect a licence file before installing it with the bundled tool:

python tools/verify_licence.py path/to/jgsc-sysmlv1-pro.licence

Expected output: Licence valid: customer=..., tier=..., seats=..., expires=...
