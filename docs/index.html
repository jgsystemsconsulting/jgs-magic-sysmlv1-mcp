JGS SysML v1 MCP Bridge

An AI-to-CATIA Magic bridge for SysML v1 models. It exposes your live SysML v1 project to Claude Code and any MCP agent over a local connection — roughly 115 model tools, with v1-native vocabulary. Air-gapped by design: the model stays inside CATIA Magic, with no cloud and no data export.

§01 — What it is

The model comes to the AI

A Java plugin inside CATIA Magic exposes SysML v1 operations as MCP tools over a local HTTP connection — read, query, and (with PRO) write.

Air-gapped

Binds to 127.0.0.1 only, offline licence validation, no network calls. Your SysML stays in CATIA Magic.

Tiered access

Read for free; write with PRO; full scripting at ENTERPRISE. One bridge, gated by your licence.

§02 — What's included

plugin/

The CATIA Magic plugin JAR — copied into your user plugins directory.

server/

The Python MCP server — pip install ./server.

docs/

Install, configuration, and licensing guides, plus the tool reference.

examples/ · tools/

A ready .mcp.json example and a read-only licence verifier.

§03 — Install

1

Install the server

pip install ./server and create your MCP client config from examples/.mcp.json.example (see docs/install.md).

2

Place the plugin & restart

Copy plugin/ into your CATIA Magic user plugins directory and restart MSOSA. This step is done on your desktop app — an agent cannot do it for you.

3

Verify

Call the ping MCP tool. If it answers, the bridge is live. See configuration.md if not.

# install the server (from the repo root)
pip install ./server

# then: copy plugin/ into CATIA Magic's plugins dir and restart MSOSA
# then: call the ping tool to confirm the bridge is reachable
